# BubbleWork · ARGtool

> 推理墙 + 密码破译台 + 简记，一个**免安装的 Windows 单文件程序**。
> 给 ARG / 解谜用的：把线索（照片、便签）钉到软木板上连线，密文交给破译台自动试各种解法。

双击 `ARGtool.exe` 就能用。

## 下载 / 运行

1. 到 [Releases](../../releases) 下载 `ARGtool.exe`（约 17 MB）
2. 双击运行，会开一个普通窗口（置顶 / 最小化 / 最大化 / 关闭）
3. 系统需要 **WebView2 运行时**（Win10/11 一般自带）；万一没有，程序会自动改用浏览器打开，
   功能一模一样，页面上会说明原因

## 界面怎么用

### 🗂 推理墙（主界面）

| 想干什么 | 怎么做 |
| --- | --- |
| 贴照片 | 点「贴图片」；也可以直接把图片拖进窗口，或者 `Ctrl+V` 粘贴 |
| 写便条 | 点「写便条」；双击便签就能改字 |
| 改大小 | 鼠标移到照片 / 便签上，拖右下角的小圆点；按住 `Shift` 拖可以锁住原来的横纵比 |
| 便签字号 | 便签上有 `A－ / A＋` 两个小按钮，单独调这一张的字号 |
| 连线 | 点一枚工字钉，再点另一枚，就用当前线色连起来；线色可以在「线色」里挑（会记住最近用过的 5 个） |
| 剪线 | 点「剪断」进剪线模式 → 点一枚**和这条线连着**的工字钉（它会变蓝）→ 再点另一端，线就取消了 |
| 移动 / 缩放墙面 | 拖空白处平移，滚轮或右下角的缩放轴缩放，右下角「复位」一键回原位 |
| 送进简记 | 点照片 / 便签右上角的小**笔**图标（在 `✕` 左边）→ 内容自动写进简记，并切到简记模式 |
| 删掉某张 | 点它右上角的 `✕` |

### 🔍 破译台（点左上角「破译台」）

把密文粘进文本框 → 点「开始破译」。两种模式：

- **智能模式**（默认）：先把 44 种手法全试一遍，**判断这段密文最像哪一种**，再按这个顺序依次给结果 ——
  最像的那种手法的结果排最上面（同一种手法里，「一层直接解出来」的排在「套娃套出来」的前面）；
  **每种手法最多 3 条、整个列表最多 15 条**，上面一行直接写着「**该段密文可能是 xx**」。
  如果填了**密钥**，会自动跳过 Base64、摩斯、进制转换这类「根本用不到密钥」的格式解码，
  优先给你真正要用密钥的手法（维吉尼亚、列换位、多字节异或）。
  **层数默认 1 层**（只直解一次，快），需要套娃解谜时在面板里调成 2 / 3 层。
- **常规模式**：自己从清单里挑一种破译方式（按经典密码 / 编码 / 现代编码 / 隐写分析分组，共 44 种），
  就只跑这一种、只显示它的结果——想验证某个猜想时用。

手法包括摩斯、Base64/32/58/85、URL / HTML 实体、进制转换、凯撒、栅栏、维吉尼亚、培根、猪圈、
Affine、Atbash、敲击码、九宫格、键盘错位、零宽字符隐写、大小写二进制、盲文…… 

每条结果都有三个按钮：

| 按钮 | 作用 |
| --- | --- |
| 复制 | 复制到剪贴板 |
| 钉到墙上 | 把「方法 + 明文」做成一张便签钉到墙上（简记模式下是插进简记里） |
| 填入输入框 | 把结果填回密文框，继续往下解一层 |

> **不支持破译中文**：中文相关解码已经停用（那类解码误报太多）。

### 📝 简记模式（点「简记」）

窗口会变成一条细长的便签：点空白处就能写，支持插图片（`Ctrl+V` 或拖进来），
支持一点 Markdown（`#` 标题、`**粗体**`、`-` 列表、`>` 引用、`` `代码` ``）。
破译台在这个界面里照样能用，解出来的结果直接插进笔记。底部可以调字号、复制全文、清空。

- 简记里的每张图片，`✕` 左边也有一个按钮：**贴到照片墙**（点一下，这张图就会出现在推理墙上）。
- 在简记里**右键**会弹出小菜单：**复制 / 粘贴 / 全选 / 张贴到墙上**。
  点在文字上：复制、张贴到墙上可用；点空白处：只有「全选」亮着（剪切板里真有东西时「粘贴」也亮）。

## 文件与数据

- **导出 / 导入**：点「导出文件」会把**整面墙 + 简记 + 里面的所有图片**打包成一个 `.lc` 文件
  （位置自己挑）；换台电脑点「导入文件」打开它就能完整还原。
  把 `.lc` 关联到 `ARGtool.exe` 之后，双击文件也能直接打开。
- **一次运行 = 一张白纸**：每次启动都是空的，**想留下的内容要先导出**。
- **关窗口前会拦一下**：还有没导出的内容时，点 `✕`（或 `Alt+F4`、任务栏关闭）会先弹一个
  「另存为 / 不保存 / 取消」；空白墙、或刚导出过，就直接关，不打扰。
- **自动兜底**：清空前会把上一轮整包存一份到 `%APPDATA%\BubbleWork\data\上一轮未保存.lc`，
  误关了可以用「导入」捡回来（每次启动覆盖上一份）。

## 常见问题

**窗口白屏 / 一启动就像卡死？**
程序会自愈：窗口打开后 15 秒还没加载出界面，就自动关掉白窗口、改用浏览器打开（功能一样）。
日志在 `%TEMP%\ARGtool_error.log`。

**重复双击会怎样？**
不会打架。同版本已经在跑 → 再开一个窗口连到同一个服务（共享同一份数据）；
后台挂着旧版本 → 新版会换个端口另起，免得被旧版顶掉。

**双击 `.lc` 没反应？**
确认关联的是这个 `ARGtool.exe`，并且没有旧版本的窗口挂在后台（见上一条）。
